# KORADE STUDIOS — FINAL EDITION

Static, responsive GitHub Pages website.

## Package contents
- `index.html` — page structure and direct official outbound links
- `style.css` — responsive visual system and immersive 2D/3D effects
- `script.js` — navigation, themes, translations, gallery, particles and interactions
- `translations.js` — English, Spanish, Portuguese, French and German
- `config.js` — official game, thumbnail, Discord, 16+ community note and credits
- `README.md` — deployment guide
- `assets/korade-crown.png` — studio crown logo

## Official destinations
- Roblox: https://www.roblox.com/es/games/137764992604751/Smash-Eggs-For-Animals
- Discord: https://discord.gg/aSZxVj3bW
- Game thumbnail: https://tr.rbxcdn.com/180DAY-95cd9d2a2922ae1f63dcdb5412f0c58d/768/432/Image/Webp/noFilter

The Play and Join Discord calls are normal HTTPS links, not JavaScript-only buttons. Their destinations are also reinforced by `script.js`.

## Deploy
1. Extract the ZIP.
2. Replace the six root files in the GitHub repository.
3. Upload the complete `assets/` folder.
4. Commit the changes and wait for GitHub Pages to deploy.
5. Hard-refresh the site.

## Notes
- No backend, API key, database, analytics, or paid service is required.
- Theme and language preferences use local browser storage when available.
- The 16+ notice is a community self-declaration, not formal age verification or a Roblox age rating.
